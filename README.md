# 📱 Mini-App 6: Hidrate-se

## 🎯 Objetivo
Aplicar conceitos de **notificações locais** e **AlarmManager** no Android.

## 📋 Funcionalidades
- Tela inicial para configurar o **intervalo de lembrete** (ex.: a cada 2 horas).
- Agendar lembretes usando **AlarmManager** ou **WorkManager**.
- Exibir **notificação** lembrando o usuário de beber água.
- Opção para **desativar os lembretes**.

## ✅ Requisitos Técnicos
- Uso de **AlarmManager** ou **WorkManager**.
- Envio de **notificações locais**.
- Interface em Compose com botões e inputs.
- Gerenciamento de estado simples para ativar/desativar alarmes.
